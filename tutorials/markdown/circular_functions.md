## Key Points

- **Sine Function**: sin is periodic with a period of 360° (or 2π radians). Thus, sin(360°) = sin(0°).
- **Cosine Function**: cos is also periodic with the same period, so cos(360°) = cos(0°).
- **Tangent Function**: tan has a period of 180° (or π radians). Thus, tan(360°) = tan(0°).

This chart covers the standard angles used frequently in trigonometry. For other angles, use the periodic properties of these functions to find their values.
